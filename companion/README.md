# MyWay Moswar Companion

Локальный сервер аппаратных кликов (`isTrusted: true`) для модуля «Рейды» скрипта
[AI MyWay DeN](../README.md).

## Зачем это нужно

Игра проверяет подлинность клика по кнопке старта боя на `/travel2/`. Событие,
созданное из JS (`new MouseEvent`, `dispatchEvent`, `el.click()`), всегда имеет
`isTrusted === false`, и сервер отвергает такой старт.

Компаньон получает команду от скрипта и выполняет настоящий клик **вне
страницы** — на уровне операционной системы. Браузер помечает его доверенным, и
игре не нужно ничего подделывать в JS.

## Быстрый старт (macOS)

Один раз — установка и проверка:

```bash
cd companion
chmod +x *.sh
./install-mac.sh
```

Скрипт сам:
1. проверит Node.js и компилятор `clang`;
2. соберёт нативный кликер из `macos_clicker.c`;
3. настроит автозапуск при входе в систему (LaunchAgent);
4. запустит Компаньон и проверит, готов ли он кликать.

После этого достаточно открыть `moswar.ru` → `/travel2/` и включить модуль
«Рейды». Компаньон уже работает в фоне.

Проверить состояние в любой момент:

```bash
./companion-mac-status.sh
```

### Единственное ручное действие macOS

Если `install-mac.sh` сообщает, что доступ Accessibility не выдан, откройте
**Системные настройки → Конфиденциальность и безопасность → Специальные
возможности** и добавьте туда исполняемый файл Node.js (скрипт установки печатает
точный путь и открывает нужное окно). Это настройка безопасности — система не
позволяет выполнить её из скрипта. Нужно один раз.

## Как это работает

```
userscript → POST http://127.0.0.1:3999/click
             {clientX, clientY, dpr, cssWidth, cssHeight, hint, url}
           → companion.js
           → bin/mw_clicker_mac --click
           → Accessibility: геометрия AXWebArea = реальный viewport
           → CoreGraphics kCGHIDEventTap: move → down → up, курсор возвращается
           → страница получает событие с isTrusted: true
```

Масштаб страницы (80 %, 100 %, 110 %) и размер окна **не влияют** на точность:
реальный масштаб считается из геометрии как `AXWebArea.width / window.innerWidth`,
а `devicePixelRatio` служит только запасной оценкой.

## Известное ограничение

Клик уровня ОС требует **активного окна**: кликер поднимает окно игры, а
свёрнутое окно не имеет валидной геометрии. Поэтому:

- вкладку игры нельзя сворачивать во время работы модуля;
- несколько профилей браузера параллельно этим путём не работают.

Фоновый и многопрофильный режим требует запуска браузера с
`--remote-debugging-port` (Chrome DevTools Protocol) — CDP кликает в окно в
любом состоянии. Это отдельная задача, см. `../HANDOFF.md`.

## Команда «вручную, без автозапуска»

Если LaunchAgent не нужен, Компаньон можно запускать из терминала — тогда он
наследует разрешение Accessibility от терминального приложения:

```bash
./start-companion-mac.sh
```

## Windows

Один двойной щелчок:

```
companion\start-companion-win.bat
```

Файл сам:

1. проверяет Node.js 22 или новее (если его нет — даёт ссылку на установщик);
2. находит Google Chrome, а если его нет — Яндекс.Браузер;
3. открывает `https://www.moswar.ru/travel2/` в отдельном профиле
   `%LOCALAPPDATA%\MyWayMoswar\Chrome` или `...\Yandex` с портом 9222;
4. запускает Companion в этом же окне.

В открывшемся окне браузера нужно один раз войти в игру. Окно браузера и
окно Companion не закрывают, пока работают рейды.

Если установлены оба браузера, берётся Chrome. Запуск именно Яндекса:

```
start-companion-win.bat yandex
```

Отдельный профиль нужен потому, что обычное уже открытое окно Chrome порт
отладки не включает. Первый вход в этом окне игра запоминает.

Запасной путь — клик через `user32.dll` (PowerShell), требует активного окна
и точных экранных координат. Пока порт 9222 не видит вкладку Мосвара,
Companion считает себя не готовым и этот запасной путь сам не включает.

## Диагностика

| Команда | Что покажет |
|---------|-------------|
| `curl -s 127.0.0.1:3999/status \| python3 -m json.tool` | полный статус: `clickReady`, `axTrusted`, `chromePid`, геометрия окна |
| `./companion-mac-status.sh` | то же в человекочитаемом виде |
| `bin/mw_clicker_mac --status` | выдан ли доступ Accessibility, масштаб дисплеев |
| `MW_CHROME_PID=<pid> bin/mw_clicker_mac --windows` | список окон браузера и геометрия web-области |
| `MW_CHROME_PID=<pid> bin/mw_clicker_mac --probe <x> <y> <dpr> "" <cssW> <cssH>` | расчёт точки клика **без** клика |
| `MW_CHROME_PID=<pid> bin/mw_clicker_mac --find-dry "Атаковать" <dpr>` | видит ли Accessibility кнопку с таким текстом |
| `MW_CHROME_PID=<pid> bin/mw_clicker_mac --dump "текст"` | все элементы с таким текстом (диагностика дерева) |

## Тест

`selftest/mw-click-test.html` — страница, которая считает **только** события с
`isTrusted === true` и выводит счётчики в заголовок окна (его читает кликер).
Откройте её в Chrome и кликните через Компаньон — счётчики `d`/`u`/`b` должны
увеличиться. `selftest/cdp-click.js` — то же для проверки CDP.

## Протокол

`GET /status` → `{ok, version, mode, clickReady, axTrusted, chromePid, window, cdp, ...}`

`POST /click` → `{success, mode, detail}` или `{success: false, error}`

Тело запроса:

| Поле | Обязательно | Назначение |
|------|-------------|-----------|
| `clientX`, `clientY` | да | координаты центра кнопки в CSS-пикселях |
| `dpr` | да | `window.devicePixelRatio` (запасная оценка масштаба) |
| `cssWidth`, `cssHeight` | да (macOS) | `window.innerWidth/innerHeight` — для точного расчёта масштаба |
| `hint` | нет | текст кнопки (диагностика, `--find`) |
| `screenX`, `screenY` | нет | резервные экранные координаты для Windows |
| `url` | нет | адрес вкладки — для выбора CDP-цели |

Сервер слушает только `127.0.0.1` и не доступен из сети.
