## 📖 Общая информация

**MoswarBot by MY WAY DEN** — единый userscript для [moswar.ru](https://www.moswar.ru). Объединяет **12 модулей** автоматизации в одну панель с планировщиком, сохранением состояния и Telegram-уведомлениями.

Рабочая копия ведётся в файле **`DEN.js`**. Перед релизом содержимое синхронизируется с GitHub userscript (`@updateURL` / `@downloadURL`).

### 🎯 Возможности

- ✅ **12 модулей** автоматизации (рейды, метро, нефть, подземка, флаг, спутники, ИИ, допы, баги, минибот, ОМОН, око)
- 🤖 **Централизованное управление** через единую панель (Hub)
- 🕐 **Автоматизация по расписанию** — интервалы и время старта модулей
- 🧠 **Ядро с планировщиком** — таймеры, конфликты локаций, восстановление после перезагрузки
- 🐀 **Крысопровод 1.9.2** — обычный / акционный / **тёмный тоннель** (коллекции, гигантский ларец, ключи на 36–40)
- 💾 **Автосохранение** настроек в `localStorage`
- 📱 **Telegram-уведомления**
- 🎨 **Гибкий UI** — перетаскивание, сворачивание, ориентация панели

### ⚠️ Важные замечания

- Скрипт работает **только в браузере** на `https://*.moswar.ru/*`
- Некоторые модули помечены как **"Демо"** (например, МиниБот) — экспериментальные
- **Не запускайте конфликтующие модули одновременно** на одной локации
- Состояние хранится в `localStorage` браузера (профиль / инкогнито = разные настройки)

## 📦 Установка

### Шаг 1: Установка Tampermonkey / Violentmonkey

1. Установите расширение:
   - **Chrome/Edge**: [Tampermonkey](https://chrome.google.com/webstore/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo)
   - **Firefox**: [Violentmonkey](https://addons.mozilla.org/firefox/addon/violentmonkey/) / Greasemonkey

### Шаг 2: Добавление скрипта

**Вариант A — с GitHub (рекомендуется для обновлений):**
1. Откройте [установку userscript](https://github.com/DeN07-ai/Moswar/raw/refs/heads/main/MoswarBot%20by%20MY%20WAY%20DEN%20.user.js)
2. Подтвердите установку в Tampermonkey

**Вариант B — из эталона `DEN.js`:**
1. Tampermonkey → «Добавить новый скрипт»
2. Вставьте содержимое файла `DEN.js` из проекта `Скрипт moswar`
3. `Файл` → `Сохранить` (`Ctrl+S` / `Cmd+S`)

### Шаг 3: Первая настройка

1. Откройте любую страницу **moswar.ru**
2. В левом верхнем углу появится панель бота (иконки модулей)
3. Нажмите ⚙️ для Telegram (по желанию)
4. Включите нужные модули кликом по иконкам

## 🖥️ Интерфейс и управление

### Панель управления (Hub)

Панель расположена в левом верхнем углу экрана.

#### Элементы интерфейса:

| Элемент | Описание |
|---------|----------|
| 🎮 **Иконки модулей** | Клик включает/выключает модуль |
| ✕ **Кнопка отключения** | Появляется при наведении на активный модуль |
| ⚙️ **Настройки** | Открытие панели настроек Telegram |
| ↔/↕ **Переключение ориентации** | Вертикальный/горизонтальный режим |
| 🤖 **Автоматизация** | Настройка расписания запуска модулей |

#### Управление:

- **Клик по иконке** — включить модуль
- **Клик по активной иконке** — открыть панель модуля
- **Наведение на иконку** — увеличение с tooltip
- **Перетаскивание иконок** — изменение порядка модулей
- **Клик по заголовку** — свернуть/развернуть панель
- **Перетаскивание панели** — перемещение по экрану

### Режимы отображения

1. **Вертикальный** (↔) — модули в столбик
2. **Горизонтальный** (↕) — модули в строку

### Сворачивание

Клик по заголовку панели сворачивает её до компактного вида. В свёрнутом состоянии видны только иконки модулей.

**Назначение:** Автоматизация Travel2 (рейдов)

**Функции:**

4. Установите стартовую страну

6. Выберите стратегию билетов (Топ-20, Смена)
7. Нажмите "▶ Старт"

**Важно:** ⚠️ Демо-модуль — может требовать ручной корректировки

### 2. 🐀 Крысопровод (v1.9.2)

**Назначение:** Автоматизация крысопровода (`/metro/`)

**Режимы:**
| Режим | Условие атаки |
|-------|----------------|
| **Обычный** | руда ≥ порога (по умолчанию 400) |
| **Акционный** | сезонный дроп (искры / снег / пули / камни / ракеты) ≥ порога; опция авто-максимума |
| **Тёмный тоннель** | целевая награда (см. ниже) |

**Общие функции:**
- Двойные спуски
- Лифт за жетоны (badge)
- Авто-сброс таймера после уровня ≥ N
- Поведение при «ниже порога»: искать другого (лифт) или убежать
- Суммарный дроп в панели

#### Тёмный тоннель — желаемая награда

В панели модуля (или в настройках МиниБота → Крысопровод) выберите **одну** цель:

1. **Элементы коллекций** (`/obj/collections/234-…`)
2. **Гигантский ларец тёмного крысопровода** — только  
   `box_metro5.png` / `data-st="8217"` / `#inventory-rat_box_5-btn`  
   (другие ларцы/сундуки **не** считаются целью)
3. **Элемент коллекции + ларец** — атака только если в награде **оба** предмета

После боя с ларцом скрипт пытается **открыть** гигантский ларец (кнопка «испол-ть» или `/player/json/use/{id}/`).

#### Правило спусков 36–40

На уровнях спуска **36–40** в тёмном тоннеле атака **только** при награде  
**ключи от сундуков крысопровода**:  
`box_metro_key.png` / `data-st="3347"`.  
Коллекции и ларец на этих спусках **не** являются основанием для нападения.

**Настройка:**
1. Включите модуль 🐀 → панель **«Крысопровод Bot v1.9.2»**
2. Выберите режим: Обычный / Акционный / **Тёмный тоннель**
3. Для тёмного тоннеля укажите награду (коллекции / ларец / оба) и поведение «искать / убежать»
4. При необходимости: жетоны лифта, авто-сброс, двойные спуски
5. Нажмите **▶ Старт**

## ⚙️ Автоматизация

### Что такое Автоматизация?

Автоматизация позволяет **запускать модули по расписанию** без вашего участия.

### Как настроить:

1. **Откройте панель Автоматизации:**
   - Кликните по иконке 🤖 в главной панели

2. **Включите автономный режим:**
   - Поставьте галочку "✅ Автономный режим"

3. **Настройте каждый модуль:**

   | Поле | Описание |
   |------|----------|
   | **Модуль** | Название модуля |
   | **Мин** | Интервал повторения в минутах (0 = один раз) |
   | **⏰** | Конкретное время запуска (HH:MM) |
   | **Авто** | Галочка для включения автозапуска |

4. **Сохраните настройки:**
   - Нажмите "💾 Сохранить расписание"
   - Или "💾 Сохранить настройки модулей" для сохранения параметров модулей

### Примеры расписания:

| Модуль | Интервал | Время | Авто | Описание |
|--------|----------|-------|------|----------|
| Крысопровод | 60 | — | ✅ | Каждые 60 минут |
| Нефтепровод | 0 | 09:00 | ✅ | Один раз в 9:00 |
| Фулл Доп | 0 | 12:00 | ✅ | В полдень |
| ОМОН | 0 | 18:00 | ✅ | В 18:00 |

### Статус TimeScheduler:

- **🟢 Запущен** — автоматизация активна
- **🔴 Остановлен** — автоматизация выключена

### ⚠️ Важные замечания по автоматизации:

1. Скрипт должен быть **открыт в браузере** в назначенное время
2. Страница **не должна быть свёрнута** (браузер может замедлить вкладку)
3. Автоматизация **не отменяет необходимость первоначальной настройки** модулей
4. Настройки модулей сохраняются отдельно от расписания

## ❓ Частые вопросы

### Q: Бот не запускается, что делать?

**A:** Проверьте:
1. Установлен ли Tampermonkey?
2. Включён ли скрипт в Tampermonkey?
3. Находитесь ли вы на странице moswar.ru?
4. Нет ли ошибок в консоли (F12 → Console)?

### Q: Модуль работает некорректно

**A:**
1. Попробуйте выключить и включить модуль заново
2. Проверьте конфликты с другими модулями
3. Обновите настройки модуля
4. Перезагрузите страницу

### Q: Как остановить все модули?

**A:**
1. Отключите каждый модуль кликом по иконке
2. Или используйте кнопку "⏹ Стоп" в панели каждого модуля

### Q: Можно ли использовать бот на нескольких аккаунтах?

**A:** Да, но для каждого аккаунта нужен отдельный браузер/профиль, так как состояние хранится в localStorage.

### Q: Бот спамит действиями

**A:** Это может быть признаком:
1. Конфликта модулей (отключите лишние)
2. Бага в демо-модуле (обновите скрипт)
3. Неправильной настройки таймеров

### Q: Как обновить бот?

**A:**
1. Возьмите актуальный `DEN.js` из проекта **Скрипт moswar** или userscript с [GitHub DeN07-ai/Moswar](https://github.com/DeN07-ai/Moswar)
2. Откройте Tampermonkey → «Редактировать»
3. Замените код на новый и сохраните (`Ctrl+S` / `Cmd+S`)

5. Проверка свежей сборки: панель крыс — **«Крысопровод Bot v1.9.2»**

### Q: В тёмном тоннеле атакует «не те» сундуки

**A:** Цель — только гигантский ларец `box_metro5` (`data-st="8217"`). Другие `box_*` игнорируются. На спусках **36–40** атака только за ключи `box_metro_key` (`3347`).

### Q: Что значит "Демо" на модуле?

**A:** Это экспериментальная или тестовая функция. Она может:
- Работать не стабильно
- Требовать ручной корректировки
- Быть в активной разработке
- Содержать баги

### Q: Как восстановить настройки после очистки браузера?

**A:** Настройки хранятся в `localStorage`. После очистки они теряются. Перенастройте модули заново.

### Хранилище данных

Все данные хранятся в `localStorage` браузера:

| Ключ | Описание |
|------|----------|
| `moswar_bot_state` / `moswar_allinone_core_v1` | Состояние модулей (вкл/выкл) |
| `ratbot-darkTunnelMode` / `ratbot-darkTunnelReward` | Режим и награда тёмного тоннеля |
| `ratbot-*` | Прочие флаги крысопровода |
| `myway_zakouloknik_timers_v2` | Таймеры модулей |
| `MYWAY_MODULE_ORDER` | Порядок модулей в панели |
| `MYWAY_PANEL_COLLAPSED` | Свернуто/развернуто |
| `MYWAY_PANEL_LAYOUT` | Ориентация панели |
| `MYWAY_ALLINONE_POS` | Позиция панели |
| `moswar_bot_config_admin` | Настройки Telegram |
