## 📖 Общая информация

**MoswarBot v1.7.2 (Smart Core)** — многофункциональный автоматизированный помощник для игры Moswar.ru. Скрипт объединяет 11 модулей автоматизации в единую систему с централизованным управлением, расписанием и умным ядром.

### 🎯 Возможности

- ✅ **11 модулей** автоматизации различных аспектов игры
- 🤖 **Централизованное управление** через единую панель
- 🕐 **Автоматизация по расписанию** — настройте время запуска модулей
- 🧠 **Smart Core** — умное ядро с обработкой конфликтов и таймеров
- 💾 **Автосохранение состояния** — восстановление после перезагрузки
- 📱 **Telegram-уведомления** — контроль через мессенджер
- 🎨 **Гибкий интерфейс** — перетаскивание, сворачивание, два режима отображения

### ⚠️ Важные замечания

- Скрипт работает **только в браузере** на странице moswar.ru
- Некоторые модули помечены как **"Демо"** — это тестовые или экспериментальные функции
- **Не запускайте конфликтующие модули одновременно** (например, два модуля для одной локации)
- Скрипт сохраняет состояние в `localStorage` браузера

## 📦 Установка

### Шаг 1: Установка Tampermonkey/Greasemonkey

1. Установите расширение для браузера:
   - **Chrome/Edge**: [Tampermonkey](https://chrome.google.com/webstore/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo)
   - **Firefox**: [Greasemonkey](https://addons.mozilla.org/firefox/addon/greasemonkey/)

### Шаг 2: Добавление скрипта

1. Откройте Tampermonkey → "Добавить новый скрипт"
2. Скопируйте код из файла `MoswarBot v1.7.2 (Smart Core).user.js`
3. Вставьте в редактор Tampermonkey
4. Нажмите `Файл` → `Сохранить` (или `Ctrl+S`)

### Шаг 3: Первая настройка

1. Откройте любую страницу **moswar.ru**
2. В левом верхнем углу появится панель бота (полупрозрачная, с иконками)
3. Нажмите на ⚙️ (шестерёнка) для настройки Telegram-уведомлений

## 🖥️ Интерфейс и управление

### Панель управления (Hub)

Панель расположена в левом верхнем углу экрана.

#### Элементы интерфейса:

| Элемент | Описание |
|---------|----------|
| 🎮 **Иконки модулей** | Клик включает/выключает модуль |
| ✕ **Кнопка отключения** | Появляется при наведении на активный модуль |
| ⚙️ **Настройки** | Открытие панели настроек Telegram |
| ↔/↕ **Переключение ориентации** | Вертикальный/горизонтальный режим |
| 🤖 **Автоматизация** | Настройка расписания запуска модулей |

#### Управление:

- **Клик по иконке** — включить модуль
- **Клик по активной иконке** — открыть панель модуля
- **Наведение на иконку** — увеличение с tooltip
- **Перетаскивание иконок** — изменение порядка модулей
- **Клик по заголовку** — свернуть/развернуть панель
- **Перетаскивание панели** — перемещение по экрану

### Режимы отображения

1. **Вертикальный** (↔) — модули в столбик
2. **Горизонтальный** (↕) — модули в строку

### Сворачивание

Клик по заголовку панели сворачивает её до компактного вида. В свёрнутом состоянии видны только иконки модулей.

## ⚙️ Автоматизация

### Что такое Автоматизация?

Автоматизация позволяет **запускать модули по расписанию** без вашего участия.

### Как настроить:

1. **Откройте панель Автоматизации:**
   - Кликните по иконке 🤖 в главной панели

2. **Включите автономный режим:**
   - Поставьте галочку "✅ Автономный режим"

3. **Настройте каждый модуль:**

   | Поле | Описание |
   |------|----------|
   | **Модуль** | Название модуля |
   | **Мин** | Интервал повторения в минутах (0 = один раз) |
   | **⏰** | Конкретное время запуска (HH:MM) |
   | **Авто** | Галочка для включения автозапуска |

4. **Сохраните настройки:**
   - Нажмите "💾 Сохранить расписание"
   - Или "💾 Сохранить настройки модулей" для сохранения параметров модулей

### Примеры расписания:

| Модуль | Интервал | Время | Авто | Описание |
|--------|----------|-------|------|----------|
| Крысопровод | 60 | — | ✅ | Каждые 60 минут |
| Нефтепровод | 0 | 09:00 | ✅ | Один раз в 9:00 |
| Фулл Доп | 0 | 12:00 | ✅ | В полдень |
| ОМОН | 0 | 18:00 | ✅ | В 18:00 |

### Статус TimeScheduler:

- **🟢 Запущен** — автоматизация активна
- **🔴 Остановлен** — автоматизация выключена

### ⚠️ Важные замечания по автоматизации:

1. Скрипт должен быть **открыт в браузере** в назначенное время
2. Страница **не должна быть свёрнута** (браузер может замедлить вкладку)
3. Автоматизация **не отменяет необходимость первоначальной настройки** модулей
4. Настройки модулей сохраняются отдельно от расписания

## ❓ Частые вопросы

### Q: Бот не запускается, что делать?

**A:** Проверьте:
1. Установлен ли Tampermonkey?
2. Включён ли скрипт в Tampermonkey?
3. Находитесь ли вы на странице moswar.ru?
4. Нет ли ошибок в консоли (F12 → Console)?

### Q: Модуль работает некорректно

**A:**
1. Попробуйте выключить и включить модуль заново
2. Проверьте конфликты с другими модулями
3. Обновите настройки модуля
4. Перезагрузите страницу

### Q: Как остановить все модули?

**A:**
1. Отключите каждый модуль кликом по иконке
2. Или используйте кнопку "⏹ Стоп" в панели каждого модуля

### Q: Можно ли использовать бот на нескольких аккаунтах?

**A:** Да, но для каждого аккаунта нужен отдельный браузер/профиль, так как состояние хранится в localStorage.

### Q: Бот спамит действиями

**A:** Это может быть признаком:
1. Конфликта модулей (отключите лишние)
2. Бага в демо-модуле (обновите скрипт)
3. Неправильной настройки таймеров

### Q: Как обновить бот?

**A:**
1. Скачайте новую версию скрипта
2. Откройте Tampermonkey
3. Нажмите "Редактировать" на текущей версии
4. Замените код на новый
5. Сохраните (Ctrl+S)

### Q: Что значит "Демо" на модуле?

**A:** Это экспериментальная или тестовая функция. Она может:
- Работать не стабильно
- Требовать ручной корректировки
- Быть в активной разработке
- Содержать баги

### Q: Как восстановить настройки после очистки браузера?

**A:** Настройки хранятся в `localStorage`. После очистки они теряются. Перенастройте модули заново.
