# AI MyWay DeN

Userscript для [moswar.ru](https://www.moswar.ru): панель модулей (рейды, крысы, нефть, подземка, флаг, спутники, ИИ, Фулл Доп и др.).

Версия: **3.9**

## Установка

1. Поставьте [Tampermonkey](https://www.tampermonkey.net/).
2. Откройте [AI MyWay DeN.user.js](https://github.com/DeN07-ai/AI-Script-MyWay-Moswar/raw/refs/heads/main/AI%20MyWay%20DeN.user.js) и подтвердите установку.
3. Зайдите на `*.moswar.ru` и включите нужные модули в панели.

Если скрипт в Tampermonkey всё ещё называется **MoswarBot by MY WAY DEN**, ничего переустанавливать не нужно: обновление идёт само. Меню расширения → «Проверить обновления скриптов».

- **Нефтепровод — управление бубой «Нефтяник»**:
  - В панели настроек Нефтепровода добавлена интерактивная круглая иконка-тоггл бубы «Нефтяник» (`/@/images/loc/buba/bubas/53.png`), стилизованная аналогично иконке «Летучик» в Крысопроводе (градиент, золотая обводка, статусная галочка `✓` в активном состоянии `is-on`, анимация при наведении).
  - При включении бот автоматически проверяет статус бубы в инвентаре Labubu (`/labubu/`) и активирует её (`action: activate`, `code: 53`) при наличии прочности.
  - Кэширование активности на 1 час (с интервалом повторной проверки 2 минуты) предотвращает избыточные сетевые запросы.
  - Пока буба активна, бот не тратит партбилеты на снижение подозрительности.
  - Реализован замок от параллельных запросов (`neftyanikActivating`) и сброс флагов при остановке бота (`stopBot`).
  - Полностью сохранена работоспособность машины состояний двойного прохождения Нефтепровода, антиспама и боевых циклов.

## Процесс подготовки релизов

### 1. Источник кода и файл совместимости
- **Основной файл:** `AI MyWay DeN.user.js` — единственный источник актуального игрового кода.
- **Файл моста:** `MoswarBot by MY WAY DEN .user.js` — генерируется автоматически сборщиком. Заголовок содержит имя совместимости (`MoswarBot by MY WAY DEN`) и `@namespace MY WAY`, а тело скрипта строго идентично основному файлу.
- **Историческая копия:** `AI MyWay DeN.js` заморожена и сборщиком никогда не затрагивается.

---

### 2. Команды сборщика (`scripts/build-release.mjs`)

Все команды выполняются из терминала:

#### А. Обычная сборка моста (без изменения версии)
```bash
node scripts/build-release.mjs
```
- Берёт код из `AI MyWay DeN.user.js` и синхронизирует `MoswarBot by MY WAY DEN .user.js`.
- Сохраняет текущую версию без изменений.
- Если мост уже актуален, файлы на диске не перезаписываются.
- При перезаписи автоматически создаёт резервную копию на Рабочем столе.

#### Б. Проверка согласованности (без изменения файлов)
```bash
node scripts/build-release.mjs --check
```
- Проверяет целостность заголовков userscript, отсутствие дублирования метаданных, совпадение версий и 100% идентичность кодовой части файлов.
- Если найдена любая ошибка, возвращает ненулевой код завершения с конкретной инструкцией по исправлению.
- **Файлы никогда не изменяются.**

#### В. Предпросмотр действий
```bash
node scripts/build-release.mjs --preview
```
- Показывает текущий статус файлов, версий и необходимость перезаписи без изменения файлов на диске.
- Для предпросмотра повышения версии: `node scripts/build-release.mjs --preview --release`.

#### Г. Подготовка нового релиза (повышение версии)
```bash
node scripts/build-release.mjs --release
```
- Автоматически рассчитывает следующий номер версии (числовой инкремент: `3.8` → `3.9` → `3.10`).
- Запрашивает явное подтверждение пользователя: `[y/N]`.
- **Как отменить:** введите `n` или нажмите Enter — операция сразу завершится, файлы останутся нетронутыми.
- При подтверждении (`y`):
  1. Создаёт резервные копии обоих файлов на Рабочем столе.
  2. Обновляет версию в основном файле и в мосте.
  3. Обновляет номер версии в `README.md`.
  4. Проверяет результат в памяти и на диске.

---

### 3. Резервные копии и безопасность

- Перед любым изменением существующих файлов создаются резервные копии в папке:
  `~/Desktop/MyWay-Moswar-release-backups/`
- Имена резервных копий включают метку времени (например, `AI-MyWay-DeN-2026-10-16T13-40-00.user.js.bak`) и никогда не перезаписывают существующие резервные копии.
- Вся генерация и проверка метаданных сначала выполняется в памяти и только при отсутствии ошибок записывается на диск.

### 4. Контроль Git и ручная публикация

> **ВАЖНО:** Локальная подготовка релиза **НЕ** отправляет файлы на GitHub и **НЕ** создаёт автоматических git-коммитов.

Перед публикацией пользователю необходимо:
1. Проверить изменения в Git:
   ```bash
   git diff
   git status
   ```
2. Убедиться, что в изменения входят только разрешённые файлы (`AI MyWay DeN.user.js`, `MoswarBot by MY WAY DEN .user.js`, `README.md`, `scripts/build-release.mjs`, `tests/build-release.test.mjs`, `tests/neft-double-pass.test.js`).
3. Запустить финальную проверку:
   ```bash
   node scripts/build-release.mjs --check
   ```
4. Вручную закоммитить и опубликовать изменения:
   ```bash
   git add "AI MyWay DeN.user.js" \
     "MoswarBot by MY WAY DEN .user.js" \
     README.md \
     scripts/build-release.mjs \
     tests/build-release.test.mjs \
     tests/neft-double-pass.test.js
   git commit -m "feat(neft): add Neftyanyk buba toggle icon and bump release to 3.9"
   git push origin main
   ```
5. Проверить доступность опубликованных URL в браузере:
   - Основной файл: `https://github.com/DeN07-ai/AI-Script-MyWay-Moswar/raw/refs/heads/main/AI%20MyWay%20DeN.user.js`
   - Мост: `https://github.com/DeN07-ai/AI-Script-MyWay-Moswar/raw/refs/heads/main/MoswarBot%20by%20MY%20WAY%20DEN%20.user.js`

### 5. Совместимость и миграция старых установок

- Мост сохраняет имя `MoswarBot by MY WAY DEN` и `@namespace MY WAY`.
- Установки скрипта, у которых в Tampermonkey прописан репозиторий `DeN07-ai/AI-Script-MyWay-Moswar`, получают обновления автоматически.
- **Ограничение:** если у кого-то из пользователей осталась очень старая установка, жестко привязанная к старому URL `DeN07-ai/Moswar`, для их обновления требуется, чтобы на стороне GitHub работал редирект репозитория `DeN07-ai/Moswar` → `DeN07-ai/AI-Script-MyWay-Moswar`, либо чтобы в старом репозитории также был опубликован актуальный мост.
