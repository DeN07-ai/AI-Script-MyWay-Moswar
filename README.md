# AI MyWay DeN

Userscript для [moswar.ru](https://www.moswar.ru): панель модулей — рейды, крысы, нефть, подземка, флаг, спутники, ИИ, Фулл Доп, закупка ТЦ, Фу-Баги, ОМОН, Око Провидения и Арена.

Версия: **3.32**

## Установка

1. Поставьте [Tampermonkey](https://www.tampermonkey.net/).
2. Откройте [AI MyWay DeN.user.js](https://raw.githubusercontent.com/DeN07-ai/AI-Script-MyWay-Moswar/refs/heads/main/AI%20MyWay%20DeN.user.js) и подтвердите установку.
3. Зайдите на `*.moswar.ru` и включите нужные модули в панели.

Если скрипт в Tampermonkey всё ещё называется **MoswarBot by MY WAY DEN**, ничего переустанавливать не нужно: обновление идёт само. Меню расширения → «Проверить обновления скриптов».

### Модуль «Рейды»: Companion (только для этой задачи)

Игра проверяет подлинность клика по кнопке старта боя (`event.isTrusted`).
Программный клик из JS сервер отвергает, поэтому клик выполняет внешний локальный
процесс — **MyWay Moswar Companion**. Без него бои в рейдах не запускаются;
остальные модули работают как обычно.

macOS — один запуск, дальше Companion стартует сам при входе в систему:

```bash
cd companion && ./install-mac.sh     # установка + проверка готовности
./companion-mac-status.sh            # диагностика в любой момент
```

Единственное ручное действие системы безопасности — выдать доступ
«Специальные возможности» для `node` (скрипт установки открывает нужное окно и
показывает точный путь). Подробно: [companion/README.md](companion/README.md).

Windows — один двойной щелчок по `companion/start-companion-win.bat`.
Файл сам находит Chrome или Яндекс.Браузер, открывает игру в отдельном
профиле с портом отладки и запускает Companion.

Нужен [Node.js 22 или новее](https://nodejs.org/en/download). В открывшемся
окне браузера нужно один раз войти в игру и не закрывать его, пока идут
рейды. Окно Companion тоже оставляют открытым. Если установлены оба
браузера, берётся Chrome. Для Яндекса: `start-companion-win.bat yandex`.

## Арена: инструкция

Модуль сам записывается на Арену в Закоулках, ставит пять приёмов выбранного режима и проводит бой. Шмот, машина и питомец в этом бою не участвуют. Окно записи открывается примерно на пять минут каждые полчаса. Один бой списывает один билет. Скрипт билеты и коробки не покупает.

Включите модуль в общей панели. Откроется окно «Арена». Выберите режим, проверьте иконки и нажмите **Старт**. Кнопку Стоп для ожидания нажимать не нужно: пока горит Старт, скрипт сам дойдёт до Закоулков, дождётся окна, запишется, выйдет на ринг и после боя снова будет ждать следующее окно.

Приёмы ставятся до записи, если они есть в сумке. Пустая сумка запись не отменяет: скрипт встаёт в очередь и проводит бой без усилений. Если перед записью здоровья меньше 80%, скрипт сначала лечится: жмёт плюс и «Вылечиться», а если этого мало — пьёт микстуру на странице персонажа и возвращается в Закоулки. Пока здоровье ниже 80%, в очередь он не встаёт. Когда персонаж уже в очереди, набор сменить нельзя: смена режима в этот момент на текущий бой не повлияет.

### Кнопки

| Кнопка | Что делает |
|--------|------------|
| Старт | Включает цикл: ждать окно, записаться, провести бой, снова ждать. Состояние сохраняется после обновления страницы. |
| Пауза | Не записывается и не ходит, пока снова не нажать Старт. |
| Стоп | Выключает модуль до нового Старта. |

Строка под кнопками показывает время следующей записи, билеты, бои за неделю и прогресс личного приза. Яркая иконка приёма есть в сумке. Серая — этого приёма нет, скрипт возьмёт замену из запаса того же режима.

### Настройки

| Настройка | Зачем |
|-----------|--------|
| Запись | Когда окно открыто, скрипт записывается сам. Без этой галочки он только готовит приёмы. |
| Приёмы | До записи ставит пять приёмов выбранного режима. |
| Приз | Забирает личный приз, когда кнопка в игре уже доступна. |
| TG | Шлёт короткое сообщение в Telegram о записи и итоге боя. |
| до | Потолок боёв за неделю. Выше этого числа скрипт новую запись не отправляет. В игре недельный потолок — 50. |

### Режимы

В каждый бой берётся не больше пяти разных приёмов. Ниже указаны основные пять. Если какого-то нет в сумке, на его место встаёт запасной приём этого же режима.

**Закалка и Таран.** Закалка, Защитная Серия, Упорный, Таран, Гомеопатия. Три удара в одну зону: третий проходит сквозь блок и может сработать как Таран. Если бой затягивается, с пятого хода входящий урон снижается.

**Ранний удар.** Таран, Стартовый натиск, Упорный, Запрет критов, Кровоточащая рана. Сильные попадания в первые ходы. Первые чужие криты по вам снимают одну жизнь.

**Нокаут.** Нокаут, Стартовый натиск, Таран, Кровоточащая рана, Гомеопатия. После двух попаданий подряд следующий удар идёт сквозь блок.

**Длинная защита.** Закалка, Защитная Серия, Двойная страховка, Ловкач, Гомеопатия. Держит одни и те же блоки, копит снижение урона и автоблок, чужое лечение срезает.

**Зеркало.** Зеркало, Двойная страховка, Защитная Серия, Чужая сила, Ответ тяжеловесу. В первые десять ходов удачный блок возвращает часть урона соперника. С пятого хода первый угаданный блок может вернуть его удар целиком, один раз за бой.

**Глухая оборона.** Глухая оборона, Закалка, Запрет критов, Защитная Серия, Гомеопатия. Первые четыре хода урон обеих сторон вдвое меньше, поэтому Таран и Стартовый натиск в этот набор не входят.

**Лечение.** Пластырь, Допинг, Дай списать, Закалка, Гомеопатия. Своё лечение и рост запаса жизней, чужие лечения срезаются. Берсерк сюда не входит: лечение подняло бы жизни выше его порога.

**Берсерк.** Берсерк, Упорный, Весомый аргумент, Закалка, Гомеопатия. Ниже 30% жизней удары становятся сильнее, к длинному бою урон растёт. Пластырь в набор не входит.

**Запас прочности.** Запас прочности, Закалка, Защитная Серия, Упорный, Гомеопатия. На седьмом ходе даёт преимущество, если у соперника больше жизней. Допинг в набор не входит: свой запас растёт, и приём может не включиться.

### Ход в бою

За ход скрипт выбирает одну атаку и две защиты, пока на ринге идёт «Тик-так». Блок ставится в две зоны, куда соперник уже попадал. Пока это неизвестно, закрыты торс и пах.

Удар не повторяет зону прошлого хода: после попадания соперник закрывает это место, после блока или мимо туда сразу не возвращаются. Через ход слабую зону можно проверить снова. Три удара в одну зону скрипт делает только если Упорный реально надет. Пробой Нокаута — только если надет Нокаут. Без этих приёмов выбранный режим рисунок боя не задаёт: скрипт бьёт туда, где блоков меньше, и в одно место два хода подряд не возвращается.

## Процесс подготовки релизов

### 1. Источник кода и файл совместимости
- **Основной файл:** `AI MyWay DeN.user.js` — единственный источник актуального игрового кода.
- **Файл моста:** `MoswarBot by MY WAY DEN .user.js` — генерируется автоматически сборщиком. Заголовок содержит имя совместимости (`MoswarBot by MY WAY DEN`) и `@namespace MY WAY`, а тело скрипта строго идентично основному файлу.
- **Историческая копия:** `AI MyWay DeN.js` хранится вне публичного репозитория и не участвует в сборке.

---

### 2. Команды сборщика (`scripts/build-release.mjs`)

Все команды выполняются из терминала:

#### А. Обычная сборка моста (без изменения версии)
```bash
node scripts/build-release.mjs
```
- Берёт код из `AI MyWay DeN.user.js` и синхронизирует `MoswarBot by MY WAY DEN .user.js`.
- Сохраняет текущую версию без изменений.
- Если мост уже актуален, файлы на диске не перезаписываются.
- При перезаписи автоматически создаёт резервную копию во внешней локальной папке резервных копий.

#### Б. Проверка согласованности (без изменения файлов)
```bash
node scripts/build-release.mjs --check
```
- Проверяет целостность заголовков userscript, отсутствие дублирования метаданных, совпадение версий и 100% идентичность кодовой части файлов.
- Если найдена любая ошибка, возвращает ненулевой код завершения с конкретной инструкцией по исправлению.
- **Файлы никогда не изменяются.**

#### В. Предпросмотр действий
```bash
node scripts/build-release.mjs --preview
```
- Показывает текущий статус файлов, версий и необходимость перезаписи без изменения файлов на диске.
- Для предпросмотра повышения версии: `node scripts/build-release.mjs --preview --release`.

#### Г. Подготовка нового релиза (повышение версии)
```bash
node scripts/build-release.mjs --release
```
- Автоматически рассчитывает следующий номер версии (числовой инкремент: `3.8` → `3.9` → `3.10`).
- Запрашивает явное подтверждение пользователя: `[y/N]`.
- **Как отменить:** введите `n` или нажмите Enter — операция сразу завершится, файлы останутся нетронутыми.
- При подтверждении (`y`):
  1. Создаёт резервные копии обоих файлов во внешней локальной папке резервных копий.
  2. Обновляет версию в основном файле и в мосте.
  3. Обновляет номер версии в `README.md`.
  4. Проверяет результат в памяти и на диске.

---

### 3. Резервные копии и безопасность

- Перед любым изменением существующих файлов создаются резервные копии в папке:
  `~/Мосвар/локальные рабочие файлы/Резервные копии/`

## Companion (MyWay Moswar Companion)

Компаньон — локальный HTTP-сервер на порту 127.0.0.1:3999, который
выполняет настоящие клики (`isTrusted: true`) на уровне операционной системы.
Без него модуль «Рейды» не запускает бои (синтетический клик сервер отвергает).

### Файлы

| Файл | Назначение |
|------|-----------|
| `companion/macos_clicker.c` | Нативный кликер (C). Собирается clang без внешних зависимостей. |
| `companion/companion.js` | HTTP-сервер: авто-компиляция кликера, поиск браузера, `/status`, `/click`. |
| `companion/install-mac.sh` | Установка: сборка + LaunchAgent + проверка готовности. |
| `companion/companion-mac-status.sh` | Диагностика: готов ли Companion к кликам прямо сейчас. |
| `companion/start-companion-mac.sh` | Разовый запуск из терминала (если не нужен автозапуск). |
| `companion/start-companion-win.bat` | Windows: один двойной щелчок. Ищет Chrome или Яндекс, открывает отдельный профиль с портом 9222 и запускает Companion. |
| `companion/selftest/` | Тестовая страница, считающая только `isTrusted: true`. |

### Как работает

```
userscript → POST /click {clientX, clientY, dpr, cssWidth, cssHeight}
           → Companion → mw_clicker_mac --click
           → Accessibility → AXWebArea (реальный viewport)
           → CoreGraphics → kCGHIDEventTap (move → down → up)
           → страница получает событие с isTrusted: true
```

Масштаб страницы (80 % / 100 % / 110 %) **не влияет** на попадание: масштаб
считается из геометрии `AXWebArea.width / window.innerWidth`,
`devicePixelRatio` — только запасная оценка.

### Состояние (2026-11-20)

- AX-клик подтверждён тестом: `isTrusted: true`, координаты совпали.
- Companion из-под launchd работает после выдачи доступа Accessibility.
- **Ограничение:** AX-клик требует активного окна (поднимает окно игры).
  Фоновая работа и параллельные профили невозможны на этом пути — см. HANDOFF.md,
  раздел «Следующие шаги».
- Windows запускается файлом `companion/start-companion-win.bat`. Готовность
  клика есть только когда на порту 9222 видна вкладка Мосвара. На живой
  Windows этот запуск ещё не подтверждался.
