# MoswarBot by MY WAY DEN

Единый userscript для [moswar.ru](https://www.moswar.ru): панель модулей, планировщик и автоматизация локаций.

**Актуальный исходник:** `DEN.js`  
**GitHub:** [DeN07-ai/Moswar](https://github.com/DeN07-ai/Moswar)

## Установка

1. Установите [Tampermonkey](https://www.tampermonkey.net/) / Violentmonkey.
2. Создайте новый скрипт и вставьте содержимое `DEN.js`, либо установите с GitHub:
   - [raw / download](https://github.com/DeN07-ai/Moswar/raw/refs/heads/main/MoswarBot%20by%20MY%20WAY%20DEN%20.user.js)
3. Откройте `https://*.moswar.ru/*` и включите нужные модули в панели.

## Крысопровод — тёмный тоннель

В режиме **Тёмный тоннель** можно выбрать целевую награду:

1. элементы коллекций  
2. гигантский ларец тёмного крысопровода (`box_metro5` / `data-st="8217"`)  
3. коллекция + ларец  

На спусках **36–40** атака только при награде **ключи от сундуков** (`box_metro_key` / `data-st="3347"`).  
После боя ларец открывается автоматически.
